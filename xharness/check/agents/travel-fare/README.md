# 國內差旅費交通費檢核（travel-fare）

BAF 核銷送出前呼叫，逐段比對交通費與機關核定的票價上限、可報支車廂等級，並找出同日重複報支的行程。低於上限不提示；只提示、不阻擋。

## 輸入

| 欄位 | 說明 |
|---|---|
| `claim_id` | 核銷單號（業務關聯識別） |
| `traveler` | 出差人 |
| `trip_date` | 出差日期（資料基準日，YYYY-MM-DD） |
| `legs[]` | 每段行程：`date`、`from`、`to`、`mode`（高鐵／臺鐵／客運）、`class`（預設標準）、`amount` |

附票根時，請求帶 `documents`，平臺回 202 與任務編號，辨識後再跑同一套規則；辨識服務未設定或連續失敗時，該筆標「附件無法判讀，轉人工」。

## 判定值表（機關維護）

- `fare_cap` 票價上限表：起站、迄站、交通工具、上限（元）
- `class_allowed` 可報支車廂等級：交通工具、車廂等級

`cases/tables.json` 只是驗證案例用的測試值，不是機關核定值。

## 規則

| 編號 | 提示 |
|---|---|
| TF-01 | 交通費高於票價上限 |
| TF-02 | 查無票價上限（轉人工） |
| TF-03 | 車廂等級不在可報支範圍 |
| TF-04 | 同日重複行程 |
