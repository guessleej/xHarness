狀態原因Agent業務鍵承辦更新

平臺上接了哪些檢核Agent、各有哪些規則、判定值與驗證狀態。新增一支不必改平臺本身。

新增一支檢核Agent

  1. 複製一支現有Agent的資料夾（例如核銷附件缺漏檢核），改 agent.toml 的代號、名稱與必要欄位。
  2. 在 rules.py 寫規則：每條一個函式，帶規則編號、依據與提示文字；只能做計算，不能連網或讀寫檔案，平臺載入前會先檢查。
  3. 在 tables.schema.toml 定義判定值表的欄位；數值由機關在「判定值」頁核定，不寫在程式裡。
  4. 在 cases/ 放驗證案例與機關核定的標準答案，三項驗證指標都要 100%。
  5. 資料夾放進設定檔 [check] agents_dirs 指定的目錄，重新啟動服務後就會出現在這一頁。

平臺從哪裡拿資料：REST API 由平臺去對方網址拉，檔案交換由對方把 CSV／JSON 放進收件匣。對方的金鑰加密後才存，只走 Authorization 標頭。

到點自動從介接取數、跑檢核，結果變成案件。時間是台北時間；伺服器停機錯過的話，回來後補跑當天那一次。
